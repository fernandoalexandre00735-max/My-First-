# ONIX
SPA mobile-first em HTML/CSS/JS puro. Inclui PWA, manifest, service worker, filtros, pesquisa, LocalStorage, player de demonstração e Analytics G-EL1DWGQKTB.

## Firebase
`js/firebase.js` é um ponto de configuração. Para Firestore em produção, crie seu projeto Firebase e implemente autenticação/regras/Cloud Functions. Não coloque segredos privados no cliente.

## Publicação
Substitua SEU-DOMINIO.example em robots.txt/sitemap.xml. Publique a pasta em Vercel ou Netlify via HTTPS. O service worker não funciona corretamente em `file://`.

## Conteúdo
Os vídeos/imagens são demonstrações. Use somente conteúdo próprio, de domínio público ou licenciado.
